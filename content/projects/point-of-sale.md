A point-of-sale system for businesses that sell both items and services: orders, reservations, discounts, taxes, gift cards, Stripe payments and SMS notifications. An ASP.NET Core 8 API with JWT auth, EF Core over PostgreSQL, Serilog logging and xUnit tests running in GitHub Actions, plus a React and TypeScript front end. Built by a team of four for a Vilnius University software design course.
